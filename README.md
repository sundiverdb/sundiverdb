# Hi, I'm Dave Broschinsky

I'm an accessibility and design systems lead in Salt Lake City. I help teams meet WCAG 2.2 AA, build design systems that stay accessible, and automate accessibility testing.

## Where to find my work

- [My portfolio at startide.net](https://startide.net)
- [Usable Patterns, my accessibility consulting practice](https://www.usablepatterns.net)

## Projects

- [A11y Agent](https://github.com/sundiverdb/A11y_Agent): audits web pages with axe-core, WAVE and Lighthouse, from a browser or as an MCP server for AI assistants.
- [Design systems](https://github.com/sundiverdb/design-systems): design tokens for my sites and apps, with every color pair checked against WCAG 2.2 AA on each build.
- [Screen reader cheat sheets](https://github.com/sundiverdb/site-assets-UP/tree/main/screen-reader-cheat-sheets): accessible PDF quick references for JAWS, NVDA, Narrator, VoiceOver and TalkBack, free to use (CC0).
